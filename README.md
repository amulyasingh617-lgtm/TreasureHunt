# TreasureHunt
C++ Treasure Hunt Maze Game using DFS, BFS and OOP concepts.

A console based maze game built using **DFS**, **BFS** and **OOP concepts**.

## 📌 Features
- Maze generation
- Path finding using BFS
- Path finding using DFS
- Object Oriented Design
- Modular multi‑file C++ project

## ⚙️ How to Run

### Clone the repository
git clone https://github.com/amulaysingh617-lgtm/TreasureHunt.git  
cd TreasureHunt

### Compile
g++ main.cpp maze.cpp bfs.cpp dfs.cpp -o treasure

### Run
./treasure
